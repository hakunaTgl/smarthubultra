📖 Smart Hub Ultra Manual

Complete guide to using Smart Hub Ultra - the AI bot management platform.

🚀 Getting Started

Smart Hub Ultra is a Progressive Web App (PWA) for creating and managing AI bots. No account required to start - use Code-First Access for instant session tracking.

  • Visit the home page to generate a 6-digit reference code.
  • Use your code to return to your session anytime without a password.
  • Navigate to the Dashboard to access all features.

🤖 Creating Bots

Navigate to Bots to create your first bot.

  • Bot Name: Must be 3-50 characters.
  • Bot Purpose: Describe what your bot does.
  • Template: Choose from Echo Bot, Greeting Bot, Support Bot, Analytics Bot, Notification Bot, or Scheduler Bot.
  • Click Create Bot to save. Bots are stored locally via IndexedDB and optionally synced to Firebase.

🎮 Playground

Test bots interactively at Playground. Select a template, type an input, and press Run Bot or hit Enter to see the response.

📝 Code Editor

Write custom bot scripts at Editor. Your code auto-saves every 30 seconds to localStorage. Use the Insert Template button to get started quickly.

🏕 Boss Intelligence Center

The Boss View provides unified oversight: People Graph, Automation Estate, Support Radar, Ops Pulse, Activity Stream, and Behavioral DNA Grid.

📊 Analytics

View bot statistics, template usage breakdowns, and activity logs at Analytics. Data is pulled from your local bot store.

🎙 Voice Control

Enable voice navigation at Voice. Uses the Web Speech API. Say commands like "Go to bots", "Open playground", or "Show boss" to navigate.

📱 PWA & Offline

Smart Hub Ultra is installable as a PWA. On Chrome/Edge, look for the install icon in the address bar. Once installed, core pages work offline via the service worker cache.

🔧 Firebase Setup (Optional)

For cloud sync and real-time collaboration, connect your Firebase project:

  • Create a project at firebase.google.com
  • Enable Authentication and Realtime Database
  • Update js/firebaseConfig.js with your project credentials
